# lib

`EDDDLLInterfaces.dll` (assembly version 2.0.0.0) is the EDDiscovery DLL interface assembly,
copied unchanged from `EDDiscovery.Portable.19.1.11.zip` (EDDiscovery release 19.1.11).
It is only referenced at compile time; EDDiscovery's own copy is used at run time.
